# TunasGrid releases

Binary distributions of the TunasGrid central server, model worker, Server Manager and Chat Client.

Download packages from this repository's Releases page. Linux and Windows archives include Java 21. Extract the complete archive and follow the included configuration instructions. Worker packages have CPU and CUDA variants; GPU use requires a compatible NVIDIA driver. Models download separately from Hugging Face and are subject to their own licenses and access requirements.

Compare downloaded files against their accompanying SHA-256 checksums. No binaries have been published yet.

Application source code is maintained in a separate private repository. This repository contains release documentation and binary release assets only.
